# Elevent Café OS — Premium Edition V3

A polished, browser-only demonstration for Elevent Web & Solutions.

## Run
Extract ZIP and open `index.html` in Chrome or Edge. Internet access is only needed for optional Google web fonts; fallback fonts work offline.

## Demonstration
- Use **Guest Menu** to place an order for any of 15 tables.
- Open **Kitchen Display** to move orders through New → Preparing → Ready → Served.
- Open **Billing Studio** to preview a café-style 80mm receipt, record a simulated payment, print through the browser, and close a paid table.
- **Floor & Tables** shows outstanding bills and opens table-specific menus.
- **Settings** allows café name, address, GSTIN demo field, table count, and illustrative tax percentage.
- Data is stored in browser localStorage.

## Important limitations
This is a single-browser prototype. Table links opened on different devices do not share data. Real QR code images, payment gateways, secure staff accounts, legally compliant GST invoice issuance, cloud sync and direct thermal printer integration require production development. Printing uses the browser print dialog and receipt styling.
